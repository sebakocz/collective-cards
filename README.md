# 🎴 Collective Cards

A fan-made companion and archive for **Collective**, a collectible card game that has since shut down.

Browse the card collection, build decks, and revisit some old favourites. A little piece of the game's history, kept alive by its community.

🌐 **[Open Collective Cards](https://sebakocz.github.io/collective-cards/)**

## 🛠️ Built with

Vue 3 · TypeScript · Pinia · Vite · Tailwind CSS
